## Quick Start

The fastest way to get started:

```bash
# macOS / Linux
chmod +x scripts/setup.sh
./scripts/setup.sh

# Windows (PowerShell)
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\scripts\setup.ps1
```

This script will:
- Validate your system dependencies
- Install Node.js modules
- Generate encryption keys
- Create `.env.local` from `.env.example`
- Configure git hooks
- Run initial tests

## Prerequisites

### System Requirements

- **Node.js**: 20.19.0+ or 22.12.0+
- **npm**: 9.0.0+
- **Git**: Latest version
- **OpenSSL**: 1.1.1+ (for key generation)
- **RAM**: 4GB minimum
- **Disk Space**: 2GB minimum

### macOS Installation

```bash
# Using Homebrew
brew install node openssl git

# Verify installation
node --version    # Should be v20.19.0 or higher
npm --version     # Should be 9.0.0 or higher
git --version     # Check you have Git
openssl version   # Should be 1.1.1 or higher
```

### Linux Installation (Ubuntu/Debian)

```bash
# Update package manager
sudo apt-get update

# Install dependencies
sudo apt-get install -y nodejs npm git openssl

# Verify installation
node --version
npm --version
git --version
openssl version
```

### Linux Installation (RHEL/CentOS/Fedora)

```bash
# Install dependencies
sudo yum install -y nodejs npm git openssl

# Verify installation
node --version
npm --version
git --version
openssl version
```

### Windows Installation

1. **Node.js**: Download from [nodejs.org](https://nodejs.org/)
   - Choose LTS version (20.x or 22.x)
   - Run installer and follow prompts
   - Verify: `node --version` in PowerShell

2. **Git**: Download from [git-scm.com](https://git-scm.com/)
   - Run installer and follow prompts
   - Enable PowerShell support

3. **OpenSSL**: Download from [slproweb.com](https://slproweb.com/products/Win32OpenSSL.html)
   - Or use: `choco install openssl` (if you have Chocolatey)
   - Add to PATH if needed

## Installation Steps

### Step 1: Clone Repository

```bash
git clone <repository-url> lucide-react
cd lucide-react
```

### Step 2: Run Setup Script

#### macOS / Linux
```bash
chmod +x scripts/setup.sh
./scripts/setup.sh
```

#### Windows (PowerShell)
```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
.\scripts\setup.ps1
```

### Step 3: Configure Environment

The setup script creates `.env.local` from `.env.example`. You must configure it:

```bash
# Edit the configuration file
nano .env.local  # macOS/Linux
# OR
code .env.local  # VS Code
```

### Step 4: Start Development

```bash
# Install dependencies (if not done by setup.sh)
npm install

# Start development server
npm run dev

# In another terminal, run tests
npm run test:watch
```

## Environment Configuration

### Essential Variables

These variables MUST be configured for the application to work:

#### API Configuration
```env
API_ENDPOINT=https://api.crmt.app
API_TIMEOUT=30000
```

#### Encryption
```env
ENCRYPTION_KEY=<32-byte base64 key>  # Generated by setup script
ENCRYPTION_ALGORITHM=aes-256-gcm
ENCRYPTION_KEY_ITERATIONS=100000
```

#### Authentication
```env
JWT_SECRET=<base64 secret>  # Generated by setup script
JWT_ACCESS_TOKEN_EXPIRY=900
JWT_REFRESH_TOKEN_EXPIRY=604800
```

### Optional but Recommended

#### Certificate Pinning
```env
API_CERT_PIN=sha256/<base64-pin>
API_CERT_PIN_BACKUP1=sha256/<base64-pin>
```

To generate certificate pins:
```bash
./scripts/generate-certs.sh
```

#### Feature Flags
```env
FEATURE_BIOMETRIC_AUTH=true
FEATURE_OFFLINE_MODE=true
FEATURE_TWO_FACTOR_AUTH=false
FEATURE_DATA_EXPORT=true
```

#### Logging
```env
LOG_LEVEL=debug  # development
DEBUG_MODE=true  # development
LOG_NETWORK_REQUESTS=true  # development only
```

## Troubleshooting

### Node.js Version Issues

**Problem:** "Node.js version X.X.X is not supported"

**Solution:**
```bash
# Check current version
node --version

# Install correct version using nvm (recommended)
nvm install 22.12.0
nvm use 22.12.0

# Or use Homebrew (macOS)
brew install node@22
brew link node@22
```

### Missing OpenSSL

**Problem:** "OpenSSL is not installed"

**Solution:**
```bash
# macOS
brew install openssl

# Linux (Ubuntu/Debian)
sudo apt-get install openssl

# Linux (RHEL/CentOS)
sudo yum install openssl

# Windows
choco install openssl
# OR download from https://slproweb.com/products/Win32OpenSSL.html
```

### npm Install Fails

**Problem:** "npm ERR! code ERESOLVE"

**Solution:**
```bash
# Use legacy peer deps flag
npm install --legacy-peer-deps

# Or clear cache
npm cache clean --force
npm install
```

### Permission Denied on Scripts

**Problem:** "./scripts/setup.sh: Permission denied"

**Solution:**
```bash
# Make scripts executable
chmod +x scripts/*.sh

# Run again
./scripts/setup.sh
```

### Port Already in Use

**Problem:** "Port 3000 is already in use"

**Solution:**
```bash
# Find process using port (macOS/Linux)
lsof -i :3000

# Kill process
kill -9 <PID>

# Or use different port
npm run dev -- --port 3001
```

### .env.local Errors

**Problem:** ".env.local not found"

**Solution:**
```bash
# Create it from template
cp .env.example .env.local

# Or run setup script
./scripts/setup.sh
```

**Problem:** ".env.local has invalid format"

**Solution:**
```bash
# Check for issues
./scripts/validate-config.sh --env

# Fix and reset if needed
cp .env.example .env.local
./scripts/dev-setup.sh --reset
```

### Git Hooks Not Working

**Problem:** "git commit/push doesn't run hooks"

**Solution:**
```bash
# Reinstall hooks
./scripts/setup.sh

# Or manually setup
mkdir -p .husky
npm install husky --save-dev
npx husky install
```

### Tests Fail

**Problem:** "npm run test fails"

**Solution:**
```bash
# Clear cache and reinstall
rm -rf node_modules package-lock.json
npm install

# Run tests with verbose output
npm run test -- --reporter=verbose

# Run specific test file
npm run test -- src/path/to/test.spec.ts
```

## Security Best Practices

### Environment Files

```bash
# Never commit .env.local
git status  # Should show .env.local is ignored

# Keep file permissions secure
ls -la .env.local  # Should show -rw------- (600)

# Backup .env.local securely
cp .env.local ~/.env.local.backup
chmod 600 ~/.env.local.backup
```

### Keys and Secrets

```bash
# Never log or print keys
echo $ENCRYPTION_KEY  # Avoid in development

# Rotate keys periodically (every 90 days)
./scripts/generate-keys.sh --rotate-encryption
./scripts/generate-keys.sh --rotate-jwt

# Store keys in secure password manager
# 1Password, LastPass, Bitwarden, etc.
```

### Git and Version Control

```bash
# Check nothing sensitive is committed
git log --all --source -- '*.env*'

# Scan for secrets in commits
git log -p | grep -i "SECRET\|PASSWORD\|KEY"

# Configure git hooks for secret detection
./scripts/setup.sh  # Sets up pre-commit hooks
```

### Development Workflow

```bash
# Always use HTTPS for API endpoints
# API_ENDPOINT=https://...  ✓
# API_ENDPOINT=http://...   ✗

# Enable certificate pinning for production
# API_CERT_PIN=sha256/...

# Use biometric auth on mobile apps
FEATURE_BIOMETRIC_AUTH=true

# Disable debug mode in production
DEBUG_MODE=false
LOG_LEVEL=warn
```

### Pre-commit Verification

Before pushing code:

```bash
# Run security validation
./scripts/validate-security.sh

# Run configuration validation
./scripts/validate-config.sh

# Run linting
npm run lint

# Run tests
npm run test
```

## Security Checklist

Before starting development:

- [ ] Node.js 20.19.0+ or 22.12.0+ installed
- [ ] npm 9.0.0+ installed
- [ ] OpenSSL installed
- [ ] `.env.local` created with real values
- [ ] Encryption key generated (not placeholder)
- [ ] JWT secret generated (not placeholder)
- [ ] `.env.local` has secure permissions (600)
- [ ] `.env.local` is in .gitignore
- [ ] Git configured with name and email
- [ ] Git hooks installed
- [ ] All tests pass: `npm run test`
- [ ] Linting passes: `npm run lint`
- [ ] No security issues: `./scripts/validate-security.sh`
