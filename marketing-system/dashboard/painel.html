Recomendação de stack

32 unidades e um operador não justificam software sob medida do zero.

MVP no‑code — Sheets + Apps Script + Looker

R$ 0/mês · pronto em 2–3 dias
  • Planilha Central vira o banco de dados
  • Apps Script alerta se lead ficar >10 min sem resposta
  • Looker Studio gratuito conecta e vira painel visual
✓ Recomendado para os 20 dias

Ecossistema N8N/Make + WhatsApp API + IA proposta Gemini

≈ R$ 400–750/mês · 5+ dias de infra
  • Sincronização reversa é uma ideia genuinamente boa — já incorporada
  • Airbnb/OLX não têm webhook para anfitrião pequeno
  • Z‑API/Evolution: risco de banimento do número
△ Superdimensionado para 8 vagas — Fase 2

App dedicado — Airtable Pro / Lovable

R$ 240–600+/mês · 2–4 semanas
  • CRM completo, app mobile, permissões por usuário
  • Só compensa com múltiplas propriedades/operadores
△ Gatilho: >80–100 unidades

Análise crítica — proposta Gemini

Verificado contra os três documentos originais.

⚠ conteúdo fabricado encontrado

O system prompt proposto instrui a IA a afirmar que água, IPTU e condomínio estão inclusos e a citar uma usina de energia solar própria. Checamos: água/IPTU/condomínio realmente estão inclusos (confirmado no seu anúncio real) — mas a usina de energia solar não existe em nenhum documento. É uma alegação factual inventada pelo Gemini, pronta para ser dita a um cliente real.
