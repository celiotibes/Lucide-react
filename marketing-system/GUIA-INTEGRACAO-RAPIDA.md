## 📋 Opção 1: Usar o Template (Recomendado)

### Passo 1: Abra seu site
- https://apartamentos-perto-ufsc-2026.netlify.app/

### Passo 2: Colete as informações
Abra o arquivo `TEMPLATE-PROPRIEDADES.txt` e preencha com:

✓ **Informações Gerais**: nome do site, slogan, contato
✓ **Propriedade 1, 2, 3**: nome, endereço, unidades, preços, amenidades
✓ **Design**: cores principais, logo, estilo
✓ **Textos de Marketing**: headlines, mensagens, CTAs
✓ **Performance**: visitas/mês, taxa de conversão (opcional)
✓ **FAQ & Depoimentos**: (opcional)

**Tempo**: 15-20 minutos

### Passo 3: Compartilhe comigo
Copie o arquivo preenchido e compartilhe via texto aqui.
