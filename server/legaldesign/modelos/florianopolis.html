Bonificação para saída em dezembro Para desocupações programadas exclusivamente no mês de dezembro: desconto de 85% sobre a multa rescisória para notificação até 22/11 com entrega das chaves até 22/12; desconto de 80% para notificação até 27/11 com entrega até 28/12. Fora dessas janelas, aplica-se o valor integral da multa proporcional.
