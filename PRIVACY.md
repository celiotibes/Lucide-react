# Privacy Policy

**Last Updated**: October 8, 2026

## 1. Introduction

This Privacy Policy describes how the Lucide React mobile application ("Application", "we", "our", or "us") collects, uses, and discloses information about you. This policy applies to all users of the Application.

## 2. Information We Collect

### 2.1 Information You Provide Directly
- Account registration information (name, email, phone)
- Profile information (avatar, preferences, settings)
- Communication data (messages, support inquiries)
- Payment information (processed securely by third parties)

### 2.2 Information Collected Automatically
- Usage analytics (features accessed, time spent)
- Device information (OS, device type, app version)
- Crash reports and error logs
- Location data (only with explicit permission)
- Camera/microphone access logs (with consent)

### 2.3 Third-Party Information
- Information from linked accounts (if applicable)
- Information from business partners (with consent)

## 3. How We Use Your Information

### 3.1 Primary Purposes
- Provide and improve the Application
- Process transactions and send confirmations
- Send transactional emails (notifications, alerts)
- Troubleshoot and provide customer support
- Develop new features and services

### 3.2 Marketing & Communications (Opt-In)
- Send promotional emails (only if you consent)
- Display personalized content
- Conduct surveys and gather feedback
- Send product updates and announcements

### 3.3 Analytics & Security
- Analyze usage patterns to improve UX
- Prevent fraud and detect security threats
- Maintain system performance and reliability
- Comply with legal obligations

## 4. Data Retention

| Data Type | Retention Period | Purpose |
|-----------|-----------------|---------|
| Account Information | While account is active + 30 days | Service provision |
| Analytics | 12 months | Performance improvement |
| Support Logs | 90 days | Customer support |
| Payment Records | 7 years | Legal/tax compliance |
| Marketing Consent | Until revoked | Communications |

## 5. Data Security

### 5.1 Encryption
- All sensitive data encrypted with AES-256-GCM
- Secure TLS 1.3+ for data transmission
- At-rest encryption for stored credentials

### 5.2 Access Controls
- Role-based access control (RBAC)
- Multi-factor authentication for administrators
- Activity logging and auditing
- Regular security audits

### 5.3 Incident Response
- 24-hour breach notification
- Credit monitoring assistance (if applicable)
- Regular security training for staff
- Incident tracking and analysis

## 6. Your Privacy Rights

### 6.1 GDPR Rights (EU Users)
- **Right to Access**: Request copy of your data
- **Right to Rectification**: Correct inaccurate data
- **Right to Erasure**: Request data deletion
- **Right to Restrict Processing**: Limit data use
- **Right to Data Portability**: Receive data in standard format
- **Right to Object**: Opt-out of processing

### 6.2 CCPA Rights (California Residents)
- **Right to Know**: Access collected data
- **Right to Delete**: Request data deletion
- **Right to Opt-Out**: Decline data sales
- **Right to Correct**: Fix inaccurate information
- **Right to Limit**: Restrict data use
- **Right to Non-Discrimination**: No penalties for exercising rights

### 6.3 LGPD Rights (Brazilian Users)
- **Right to Access**: Obtain your data
- **Right to Correction**: Fix inaccurate data
- **Right to Deletion**: Request data removal
- **Right to Data Portability**: Export data
- **Right to Object**: Challenge processing
- **Right to Revoke Consent**: Withdraw agreement
