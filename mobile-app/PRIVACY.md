## 5. User Data Rights

### 5.1 GDPR Rights (Europe)

**Right to Access (Article 15)**
- Request and receive copy of personal data
- Understand how data is processed
- Know who it's shared with

**Right to Rectification (Article 16)**
- Correct inaccurate data
- Complete incomplete data
- Update outdated information

**Right to Erasure (Article 17)**
- Request permanent deletion ("Right to be Forgotten")
- Deletion within 30 days
- No retention for legitimate interests

**Right to Restrict Processing (Article 18)**
- Stop processing for non-essential purposes
- Retain data without processing
- Resume with your consent

**Right to Data Portability (Article 20)**
- Export data in structured format
- Machine-readable format (JSON, CSV)
- Transfer to another service

**Right to Object (Article 21)**
- Opt-out of processing
- Stop marketing communications
- Prevent profiling

**Right to Withdraw Consent**
- Withdraw at any time
- No penalty for withdrawal
- Effective immediately

### 5.2 CCPA Rights (California)

Users in California have the right to:

1. **Know** what personal information is collected
2. **Delete** personal information we collect
3. **Opt-out** of sale or sharing of personal information
4. **Correct** inaccurate personal information
5. **Limit** use and disclosure to necessary purposes
6. **Non-discrimination** for exercising CCPA rights

We do NOT sell personal information and do not discriminate against users who exercise their rights.

### 5.3 LGPD Rights (Brazil)

Users in Brazil have the right to:

1. Confirm existence of processing
2. Access personal data
3. Correct incomplete, inaccurate data
4. Block processing
5. Request deletion
6. Request portability
7. Access processing logs
8. Request processing information

### 5.4 How to Exercise Your Rights

To exercise any of these rights, contact:

**Email**: privacy@crmt.app  
**Postal**: CRMT Privacy Team, [Address]  
**Response Time**: Within 30 days (45 days for complex requests)  
**No Fee**: Unless requests are manifestly unfounded

## 6. Data Retention & Deletion

### 6.1 Retention Schedule

| Data Type | Retention Period | Reason |
|-----------|------------------|--------|
| Account Data | Duration of account | Service provision |
| Financial Records | 2 years | Legal/Tax compliance |
| Audit Logs | 1 year | Security & compliance |
| Document Scans | 1 year | Service history |
| Support Messages | 1 year | Customer support |
| Analytics Data | 1 year | Performance improvement |
| Location Data | 30 days | Security only |
| Deleted Account | 90 days | Recovery period, then deleted |

### 6.2 Automatic Deletion

Data is automatically deleted after the retention period:
- Batch deletion runs monthly
- Secure deletion using cryptographic erasure
- Backup retention: up to 30 days after deletion

### 6.3 Manual Deletion Requests

Users can request immediate deletion:
1. Go to Settings > Privacy > Delete My Data
2. Confirm deletion (irreversible)
3. Data deleted within 24 hours
4. Confirmation email sent

## 7. Data Security

### 7.1 Encryption

- **At Rest**: AES-256-GCM encryption
- **In Transit**: TLS 1.3 minimum
- **Keychain/Keystore**: OS-level secure storage
- **Master Keys**: Rotated every 90 days
- **Zero-Knowledge**: Server never stores plaintext passwords

### 7.2 Access Controls

- Role-based access control (RBAC)
- Principle of least privilege
- Multi-factor authentication for admins
- Audit logging for all data access

### 7.3 Infrastructure Security

- ISO 27001 certified data centers
- DDoS protection
- Intrusion detection systems
- Regular security audits
- Bug bounty program

## 12. Data Breach Notification

### 12.1 Breach Response

In case of data breach:

**Immediately** (0-24 hours)
- Contain the breach
- Identify affected data
- Assess impact

**Short-term** (1-3 days)
- Internal investigation
- Notify data protection authority
- Prepare user notifications

**User Notification** (3-7 days)
- Email to registered address
- Describe nature of breach
- Data affected
- Mitigating measures taken
- Support contact information

### 12.2 Regulatory Notification

- **GDPR**: Notify DPA within 72 hours
- **LGPD**: Notify ANPD immediately
- **CCPA**: Notify California AG without delay
- **CASL**: Notify PIPEDA (if Canadian)
