## Introduction

The CRMT Mobile App is a comprehensive document management and transaction tracking application designed for Android and iOS devices. It allows you to capture, organize, and manage your financial documents and transactions on the go with powerful offline functionality.

### Key Features

- **Document Capture**: Take photos of receipts, invoices, and financial documents
- **OCR Processing**: Automatic text recognition from captured documents
- **Offline-First**: Work without internet and sync automatically when connected
- **Transaction Management**: Track and categorize your financial transactions
- **Analytics Dashboard**: Visualize your financial data with charts and reports
- **Biometric Authentication**: Secure your account with fingerprint or face recognition
- **Real-Time Sync**: Keep your data updated across all your devices
- **Push Notifications**: Get alerts about important events and document processing

### System Requirements

**For Android:**
- Android 10 or higher
- 100 MB free storage space minimum
- Internet connection for initial setup and sync (not required for daily use)

**For iOS:**
- iOS 15 or higher
- 100 MB free storage space minimum
- Internet connection for initial setup and sync (not required for daily use)

## Installation

### Installing on Android

#### Method 1: Using Google Play Store (Recommended)

1. Open the **Google Play Store** app on your Android device
2. Search for "CRMT Mobile" in the search bar
3. Tap the app icon from Accounting & Legal Mobile Solutions
4. Click the **"Install"** button
5. Review the permissions requested and tap **"Install"**
6. Wait for the installation to complete (usually 1-2 minutes)
7. Tap **"Open"** to launch the app for the first time

#### Method 2: Direct APK Installation

1. Download the APK file from the official website or your organization's portal
2. Open your file manager and navigate to the Downloads folder
3. Locate the CRMT APK file and tap it
4. If prompted, enable "Unknown Sources" in your device settings
5. Follow the on-screen prompts to complete installation
6. Tap "Open" to launch the app

#### Post-Installation Setup

After installation:

1. Grant the necessary permissions:
   - **Camera**: Required for document capture
   - **Photo Library**: To select existing photos for processing
   - **Storage**: To save captured documents and data
   - **Location** (optional): For geolocation features

2. Check for app updates in the Play Store to ensure you have the latest version
3. Allow sufficient time for the initial database setup on first launch

### Installing on iOS

#### Method 1: Using Apple App Store (Recommended)

1. Open the **App Store** app on your iOS device
2. Tap the **Search** tab at the bottom
3. Search for "CRMT Mobile"
4. Tap the **Get** button
5. Use Face ID, Touch ID, or your Apple ID password to authorize
6. Wait for the download and installation (usually 1-2 minutes)
7. Tap **Open** to launch the app

#### Method 2: TestFlight Beta (For Beta Testing)

1. Download the **TestFlight** app from the App Store
2. Use the beta link provided to you
3. Install the beta version following the on-screen instructions
4. Note: Beta versions may have additional features but are not production-ready

#### Post-Installation Setup

After installation:

1. Grant necessary permissions:
   - **Camera Access**: For document capture
   - **Photo Library Access**: To select photos
   - **Location** (optional): For geolocation features

2. Update to the latest version if prompted
3. Allow the app to set up its local database

## Getting Started

### First-Time Launch

When you open CRMT Mobile for the first time:

1. **Welcome Screen**: You'll see a welcome screen with app information
2. **Login/Registration**: Create a new account or log in with existing credentials
3. **Set Up Biometric**: Optionally set up fingerprint or face recognition for faster access
4. **Permissions**: Grant necessary app permissions
5. **Initial Sync**: Allow time for the app to sync with the server (3-5 minutes)
6. **Dashboard**: You'll be taken to the main dashboard

### Creating Your Account

1. On the login screen, tap **"Don't have an account? Sign up"**
2. Enter your **email address**
3. Create a **strong password** (minimum 8 characters, including uppercase, lowercase, and numbers)
4. Enter your **full name**
5. Select your **organization** (if applicable)
6. Read and accept the **Terms of Service** and **Privacy Policy**
7. Tap **"Create Account"**
8. Verify your email address using the verification link sent to your inbox
9. Return to the app and log in with your new credentials

### Setting Up Biometric Authentication

1. Navigate to **Settings** → **Security**
2. Tap **"Set Up Biometric Authentication"**
3. Choose **"Fingerprint"** or **"Face Recognition"** (depending on device capability)
4. Follow the on-screen prompts to register your biometric
5. For Android: You may need to go to device Settings to set up fingerprint/face
6. Once set up, you can unlock the app using your biometric instead of password

### Navigating the App

The app uses a bottom tab navigation:

- **Dashboard**: Home screen with overview and quick actions
- **Documents**: Manage all captured and processed documents
- **Transactions**: View and categorize financial transactions
- **Notifications**: Check alerts and processing status
- **Settings**: Configure app preferences and account settings

## Feature Descriptions

### Dashboard

The Dashboard is your home screen showing:

- **Quick Stats**: Summary cards showing document count, pending transactions, sync status
- **Recent Documents**: Latest documents you've captured or uploaded
- **Quick Actions**: Buttons to start a new document capture or add a transaction
- **Sync Status**: Indicator showing whether your data is synced with the server
- **Network Status**: Shows if you're online or offline

### Document Capture & Processing

#### Capturing Documents

1. From any screen, tap the **"+"** button or navigate to **Documents** → **New**
2. Choose **"Take Photo"** to use the camera or **"Select from Library"** to use existing photos
3. For taking photos:
   - Hold your device at a 45-degree angle to the document
   - Ensure adequate lighting without glare
   - The app will show a green border when the document is properly framed
   - Tap the camera button to capture
4. Review the captured image and tap **"Process"** or **"Retake"**

#### Processing Documents

Once captured, the app automatically:

1. **Enhances** the image for better readability
2. **Extracts Text**: Uses OCR to read text from the document
3. **Detects Type**: Identifies if it's an invoice, receipt, or other document type
4. **Extracts Fields**: Pulls out key information (date, amount, vendor, etc.)
5. Shows processing progress with percentage indicator
6. Allows you to review and edit extracted information

#### Saving and Organizing

1. After processing, review the extracted information
2. Make corrections if needed by tapping on the field
3. Add **tags** or **categories** for easy searching
4. Assign to a **project** or **category**
5. Add **notes** for additional context
6. Tap **"Save"** to store the document

### Transaction Management

#### Creating Transactions

1. Go to **Transactions** → **"+"** button
2. Fill in the transaction details:
   - **Type**: Income or Expense
   - **Amount**: Transaction amount
   - **Date**: Date of transaction
   - **Category**: Select a category (Sales, Utilities, Salaries, etc.)
   - **Description**: Add notes
   - **Payee/Payer**: Who the transaction involves
3. Optionally **attach a document** by selecting a captured document
4. Tap **"Save"**

#### Categorizing Transactions

1. Select a transaction from the **Transactions** list
2. Tap **"Edit"**
3. Choose the correct **Category** from the dropdown
4. Assign **Tags** for additional organization
5. Tap **"Save"**

#### Viewing Transaction History

1. Go to **Transactions** tab
2. Use filters to view by:
   - **Date Range**: Select custom dates
   - **Category**: Filter by specific categories
   - **Amount Range**: Filter by transaction amount
   - **Status**: View pending, completed, or all transactions
3. Tap a transaction to view full details
4. Use **"Export"** to save transaction data

### Analytics Dashboard

The Analytics feature provides insights into your financial data:

1. Navigate to **Transactions** → **Analytics** or use the analytics widget on Dashboard
2. View charts and statistics including:
   - **Expense Breakdown**: Pie chart showing spending by category
   - **Income vs. Expenses**: Line chart over selected period
   - **Monthly Trends**: Historical data visualization
   - **Category Totals**: Summary table of spending by category
3. Customize the period using date selectors
4. Export reports as PDF or CSV

### Settings

#### Account Settings

1. Go to **Settings** → **Account**
2. Update your **profile information** (name, email)
3. Change your **password**
4. Manage **linked devices**
5. View your **subscription status**

#### Security Settings

1. Go to **Settings** → **Security**
2. Enable/disable **biometric authentication**
3. Set **auto-lock timeout** (how long before app locks)
4. View **active sessions**
5. **Revoke** access from devices you no longer use
6. Review **security activity** log

#### Notification Settings

1. Go to **Settings** → **Notifications**
2. Toggle notifications **On/Off** for:
   - Document processing complete
   - Transaction alerts
   - Sync notifications
   - System updates
3. Set **notification sound** and **vibration**
4. Choose **quiet hours** when notifications won't appear

#### Data & Sync Settings

1. Go to **Settings** → **Data**
2. View **storage usage** and breakdown
3. Configure **auto-sync** settings:
   - Sync frequency
   - Only sync on WiFi (to save data)
4. View last **sync time** and status
5. Manually trigger a sync by tapping **"Sync Now"**
6. Choose what data types to sync (documents, transactions, etc.)

## Step-by-Step Tutorials

### Tutorial 1: Capturing and Processing Your First Receipt

**Objective**: Learn how to capture a receipt and have it automatically processed.

**Time**: 5-10 minutes

**Steps**:

1. Tap the **"+"** button on the Dashboard or go to **Documents** → **"New"**
2. Select **"Take Photo"**
3. Position your phone so the receipt is in the frame:
   - The app will show corners when the document is detected
   - Ensure even lighting and no shadows
   - The background should be contrasting (dark table, light wall, etc.)
4. When ready (green border appears), tap the camera icon
5. Review the captured image in the preview
6. Tap **"Process"** to start OCR processing
7. Wait for processing to complete (usually 5-15 seconds depending on image quality)
8. Review the extracted fields:
   - **Date**: Receipt date
   - **Total**: Receipt total amount
   - **Vendor**: Store/restaurant name
   - **Category**: Auto-detected (you can change)
9. Tap on any field to edit the extracted text if needed
10. Add a **note** if desired (e.g., "Team lunch")
11. Tap **"Save"** to store the receipt
12. The receipt is now available in your **Documents** section

### Tutorial 2: Tracking Monthly Expenses

**Objective**: Categorize and track your monthly expenses.

**Time**: 15-20 minutes

**Steps**:

1. Go to the **Transactions** tab
2. Set a filter for the current month:
   - Tap the date selector
   - Choose "This Month" or custom dates
3. Review all transactions displayed
4. For uncategorized transactions:
   - Tap the transaction
   - Tap **"Edit"**
   - Select the appropriate **Category**
   - Tap **"Save"**
5. View the Analytics:
   - Scroll down or tap **"Analytics"** button
   - See your expense breakdown by category
6. Identify high-spending categories:
   - The pie chart shows the largest spending areas
   - Consider if you can reduce spending
7. Export your monthly report:
   - Tap the **"Export"** button
   - Choose **PDF** or **CSV** format
   - Share or save the file

### Tutorial 3: Syncing Data Across Devices

**Objective**: Ensure your data is synced to the cloud and available on other devices.

**Time**: 5 minutes

**Steps**:

1. Go to **Settings** → **Data**
2. Check the **"Last Sync Time"** to see when data was last synced
3. Ensure you're connected to the internet (WiFi or cellular)
4. Tap **"Sync Now"** to manually sync data
5. Watch the sync progress indicator
6. Once complete, you'll see "Sync successful"
7. Go to another device where you've installed the app
8. Log in with the same account credentials
9. Go to **Settings** → **Data**
10. Tap **"Sync Now"**
11. Your documents and transactions should now appear on this device

### Tutorial 4: Setting Up Biometric Login

**Objective**: Speed up your login process with biometric authentication.

**Time**: 5 minutes

**Steps**:

1. Go to **Settings** → **Security**
2. Tap **"Set Up Biometric Authentication"**
3. Choose **"Fingerprint"** or **"Face Recognition"**
4. If prompted, go to your device **Settings**:
   - **Android**: Settings → Security → Fingerprint/Face (varies by device)
   - **iOS**: Settings → Face ID & Passcode or Touch ID & Passcode
5. Register your biometric using the device settings
6. Return to the CRMT app
7. Tap **"Enable Biometric"** to confirm setup
8. Lock the app by closing it or tapping the lock icon
9. Re-open the app and use your biometric to unlock instead of password

### Tutorial 5: Recovering a Lost or Forgotten Password

**Objective**: Regain access if you forget your password.

**Time**: 10 minutes

**Steps**:

1. On the login screen, tap **"Forgot Password?"**
2. Enter your registered **email address**
3. Tap **"Send Reset Link"**
4. Check your email for a password reset link (may take 5 minutes)
5. Tap the link in the email
6. Create a new **strong password**
   - Minimum 8 characters
   - Include uppercase, lowercase, numbers, and special characters
   - Example: `MyPassword2024!`
7. Confirm your new password
8. Tap **"Reset Password"**
9. Return to the app
10. Log in with your new password
11. You're now back in the app

## FAQs

### Account & Authentication

**Q: I forgot my password. How do I reset it?**

A: On the login screen, tap "Forgot Password?" Enter your email and follow the reset link sent to your inbox. Create a new password and you'll be able to log in.

**Q: Can I use the same account on multiple devices?**

A: Yes! Log in with the same email and password on any device. Your data will automatically sync across all devices when connected to the internet.

**Q: What should I do if I lose access to my biometric device?**

A: You can always log in using your password. Go to Settings → Security to disable biometric authentication and set up on a new device.

**Q: Is my password encrypted?**

A: Yes. We use industry-standard encryption (AES-256) for all passwords stored on our servers. Passwords are never sent in plain text.

### Document Capture & Processing

**Q: Why is my document OCR result inaccurate?**

A: Document quality significantly affects OCR accuracy. Try:
- Better lighting (avoid shadows and glare)
- Clear, unfolded documents
- Higher resolution photos
- Images without handwriting mixed with printed text

**Q: Can I capture documents that are already images on my phone?**

A: Yes! When creating a new document, tap "Select from Library" instead of "Take Photo" to choose existing images.

**Q: What file formats are supported?**

A: CRMT Mobile supports:
- JPEG (.jpg)
- PNG (.png)
- PDF (.pdf)
- TIFF (.tiff)

**Q: Can I undo document processing?**

A: You can delete a processed document and recapture it. Go to Documents, swipe left on a document, and tap "Delete."

**Q: What happens to documents when I'm offline?**

A: Documents are saved locally when offline. Once you reconnect to the internet, they automatically sync to the server.

### Transactions & Analytics

**Q: Can I import transactions from other apps?**

A: Currently, manual entry is supported. We're working on CSV import for a future version.

**Q: How far back can I view transaction history?**

A: You can view all transactions ever recorded in your account. Filter by date to find specific periods.

**Q: Can I export my data?**

A: Yes! Go to Transactions → Analytics → Export to save as PDF or CSV. You can also export individual documents.

**Q: What categories are available?**

A: Default categories include: Sales, Salaries, Utilities, Office Supplies, Travel, Meals, Rent, Equipment, and more. You can request custom categories from your administrator.

### Sync & Offline Usage

**Q: Does the app work offline?**

A: Yes! You can capture documents and add transactions while offline. Data syncs automatically when you reconnect.

**Q: How much data can I store offline?**

A: Typically 500-1000 documents depending on your device storage. Larger documents use more space.

**Q: When does the app automatically sync?**

A: By default, the app syncs:
- When you log in
- When you first open the app if internet is available
- Periodically while you're using the app (every 5-10 minutes)
- When you explicitly tap "Sync Now"

**Q: Why hasn't my data synced yet?**

A: Check:
- Are you connected to the internet?
- Is WiFi or cellular data enabled?
- Do you have sufficient data quota?
- Try manually tapping "Settings" → "Data" → "Sync Now"

### Security & Privacy

**Q: Is my data private and secure?**

A: Yes. We use:
- HTTPS/TLS encryption for all data in transit
- AES-256 encryption for data at rest
- Certificate pinning to prevent man-in-the-middle attacks
- Regular security audits
- No data sharing with third parties

**Q: How do I securely delete data?**

A: Go to Settings → Data → "Delete All Local Data" or delete individual documents by swiping and tapping delete.

**Q: Who has access to my documents?**

A: Only you and authorized users you share documents with. Your organization's administrators may have limited access for audit purposes.

**Q: Can I view activity logs?**

A: Yes. Go to Settings → Security to view your login history and device access logs.

### Technical & Troubleshooting

**Q: Why is the app slow?**

A: Try:
- Restart the app
- Clear app cache (Settings → Apps → CRMT Mobile → Storage → Clear Cache)
- Ensure sufficient device storage (at least 100 MB free)
- Update to the latest app version

**Q: The app keeps crashing. What should I do?**

A: Try these steps in order:
1. Restart your phone
2. Reinstall the app
3. If issues persist, contact support (see Support section)

**Q: Can I move documents between categories?**

A: Yes. Open a document, tap "Edit" and change the category/tags as needed.

**Q: How do I contact support if I have a problem?**

A: See the "Support and Contact" section below for multiple contact options.

## Troubleshooting

### App Won't Launch

**Problem**: App crashes or won't open after tapping the icon.

**Solutions**:
1. Wait 10-15 seconds and try again
2. Restart your device
3. Ensure you have at least 100 MB free storage
4. Uninstall and reinstall the app
5. Contact support if the issue persists

### Login Issues

**Problem**: Getting "Invalid credentials" error even with correct password.

**Solutions**:
1. Ensure CAPS LOCK is off
2. Check your internet connection
3. Wait 5 minutes (may be server maintenance)
4. Use "Forgot Password" to reset
5. Check if your account has been deactivated

### Camera Not Working

**Problem**: Camera permission denied or camera won't open.

**Solutions**:
1. Go to Settings → Apps → CRMT Mobile → Permissions → Camera
2. Ensure Camera permission is "Allowed"
3. Restart the app
4. If using Android, check if device has camera (tablets may not)
5. Restart your device

### Documents Not Syncing

**Problem**: Documents or transactions aren't appearing on other devices.

**Solutions**:
1. Check internet connection (WiFi or cellular data)
2. Manually sync: Settings → Data → Sync Now
3. Wait 5 minutes for automatic sync
4. Log out and log back in
5. Check if sync is disabled in Settings → Data
6. Ensure both devices have enough free storage

### OCR Not Working Properly

**Problem**: Extracted text is inaccurate or contains errors.

**Solutions**:
1. Ensure adequate lighting on document
2. Hold device at 45-degree angle
3. Avoid shadows and glare on document
4. Use higher resolution photos
5. Ensure text is printed (not handwritten)
6. Try a different angle or distance
7. Manually correct extracted text and save

### Battery Drain

**Problem**: App is using too much battery.

**Solutions**:
1. Disable automatic sync: Settings → Data → Auto Sync Off
2. Turn off push notifications: Settings → Notifications
3. Use WiFi instead of cellular for sync
4. Close unnecessary background apps
5. Reduce screen brightness while using the app

### Storage Running Out

**Problem**: Device storage is full.

**Solutions**:
1. Delete old documents you no longer need
2. Clear app cache: Settings → Apps → CRMT Mobile → Clear Cache
3. Uninstall unused apps
4. Consider upgrading device storage
5. Use cloud sync instead of storing all locally
